Lesson 1 · the cascaded loop

Make a call and watch the pieces cooperate.

The production-shaped learning loop is deliberately separate: caller speech → STT → agent plus tools → TTS → spoken reply. The mock provider lets the same boundaries run offline.

Caller“I need a room from August 12 to August 14 for two guests.”
1. Capture

Mic mode records 16 kHz PCM until a caller pause.

voice_loop.py
2. STT

Speech becomes a transcript the system can inspect.

provider.transcribe()
3. Agent

Rules decide whether to answer, call a tool, transfer, or end.

agent.respond()
4. Tool loop

Trusted operational data returns to the agent before it speaks.

run_tool()
5. TTS / control

The agent speaks; transfer or hangup can stop the loop.

provider.synthesize()
Ready: Pick a caller request, then run the walk-through.
Why cascade?Each stage is measurable, easy to replace, and easy to rehearse. The terminal reports STT, LLM/tool, and TTS timings separately instead of hiding them inside a black box.
