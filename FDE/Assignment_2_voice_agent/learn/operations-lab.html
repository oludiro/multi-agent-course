Turn detection

When should Aurora answer?

Microphone mode uses WebRTC voice activity detection (VAD) and waits for a silence timeout. Move the slider to feel the tradeoff. The code default is 600 ms.

Fast, risk of cutting off pausesForgiving, more waiting
Caller speech → listening for 600 ms of silence
Workshop default: 600 ms is a balanced teaching setting. Higher VAD aggressiveness can reduce noise triggers but may miss quieter speech.
